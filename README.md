## 🌐 Featured Projects

### 🔹 Backend Development

- 🚀 [Task Manager API](https://github.com/Groydewut/Task-Manager---API-) — REST API built with Go and PostgreSQL. Features CRUD operations, filtering, pagination, database migrations, Docker, graceful shutdown and structured logging.

- 💰 [CLIExpense](https://github.com/Groydewut/ProjecktExpense) — Fullstack expense tracker with user registration, JWT authentication, bcrypt password hashing and PostgreSQL. Includes user-specific data isolation and a web interface.

- 📄 [Counter-DOCX](https://github.com/Groydewut/Counter-DOCX) — Go web application for estimating the number of pages in DOCX documents. Implements file validation, DOCX parsing, XML processing and HTTP file uploads.

### 🔹 Desktop Applications

- ⏱️ [Go Timer](https://github.com/Groydewut/MyTimer) — Desktop countdown timer built with Go, Wails and Svelte. Includes pause, resume, presets, notifications and light/dark themes.

- 🧮 [Calculator](https://github.com/Groydewut/Calculator) — Desktop calculator built with Go and Wails. Supports arithmetic operations, error handling and persistent calculation history using JSON.

### 🔹 CLI Tools

- 🔐 [Passgen](https://github.com/Groydewut/passgen) — Command-line password generator written in Go. Uses cryptographically secure randomness (`crypto/rand`) and supports three password complexity levels.

### 🔹 Web Development

- 🌍 [Personal Portfolio](https://github.com/Groydewut/portfolio_website) — Personal portfolio website built with Go, HTML, CSS and JavaScript. Includes a contact form, email integration, input validation and rate limiting.
